# Exercícios Front-End — FIAP

Repositório com os exercícios práticos de desenvolvimento front-end realizados ao longo do curso de Sistemas de Informação na FIAP.

Cada pasta corresponde a um exercício da trilha de **Front-END do Nano**, desenvolvidos com HTML, CSS e JavaScript.

---

## Exercícios

| Pasta | Conteúdo | Tecnologias |
|-------|----------|-------------|
| [hands-on-01](./hands-on-01/) | Página web básica com estrutura HTML e estilização CSS | HTML, CSS |
| [hands-on-02](./hands-on-02/) | Componente de redes sociais com ícones | HTML, CSS, Font Awesome |
| [hands-on-03](./hands-on-03/) | Landing page com seção hero e galeria de imagens | HTML, CSS |
| [hands-on-04](./hands-on-04/) | Layout de página com header, seções e imagens | HTML, CSS, Google Fonts |
| [hands-on-05](./hands-on-05/) | Layout responsivo com múltiplas seções | HTML, CSS, Google Fonts |
| [hands-on-06](./hands-on-06/) | Formulário de cadastro com layout moderno | HTML, CSS, Font Awesome |
| [hands-on-07](./hands-on-07/) | Site de hotel responsivo com banner e seções de conteúdo | HTML, CSS, Font Awesome |
